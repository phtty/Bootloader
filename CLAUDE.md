# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

STM32H750VBTx Bootloader project, generated by STM32CubeMX v6.14.1. Target chip has only 128KB internal flash — external QSPI flash provides additional storage. The bootloader receives firmware via USART1 and programs it.

## Build Commands

```bash
make          # Build: generates build/Bootloader.elf, .hex, .bin
make clean    # Delete build/ directory
```

Toolchain: `arm-none-eabi-gcc` (must be on PATH or set `GCC_PATH`).
Optimization: `-Og`, debug symbols enabled (`-g -gdwarf-2`).

## Architecture

### Memory Layout (linker script: `STM32H750XX_FLASH.ld`)

| Region   | Address      | Size  | Notes                          |
| -------- | ------------ | ----- | ------------------------------ |
| ITCMRAM  | `0x00000000` | 64K   |                                |
| FLASH    | `0x08000000` | 128K  | Internal, read-only            |
| DTCMRAM  | `0x20000000` | 128K  | .data, .bss, heap, stack       |
| RAM (D1) | `0x24000000` | 512K  |                                |
| RAM_D2   | `0x30000000` | 288K  |                                |
| RAM_D3   | `0x38000000` | 64K   |                                |
| QSPI     | `0x90000000` | —     | External flash, memory-mapped  |

### Clock Tree

- **HSE** → PLL1 (÷8, ×128, ÷2) → **200 MHz** SYSCLK / HCLK / Cortex
- **HSE** → PLL2 (÷16, ×128, ÷2) → QSPI at 100 MHz, USART1 at 50 MHz
- PWR: LDO supply, voltage scaling 3

### MPU Configuration (`Core/Src/main.c` — `MPU_Config`)

Deny-by-default strategy with selective whitelisting:
1. **Region 0**: Deny entire 4GB (background), except sub-regions 0,1,2,7 (`SubRegionDisable=0x87`)
2. **Region 1**: `0x90000000`, 8MB — full access, executable, cacheable (QSPI flash)
3. **Region 2**: `0x20000000`, 1MB — full access, NOT cacheable (DTCM)

I-Cache and D-Cache are enabled after MPU config, before HAL init.

### Peripherals

| Peripheral | Details                                                  |
| ---------- | -------------------------------------------------------- |
| QUADSPI    | Single bank, FlashSize=23 (8MB), prescaler=0, half-cycle sample shift |
| USART1     | 115200-8N1, DMA RX (DMA1_Stream0, peripheral→memory, byte-aligned, normal mode) |
| GPIO       | QSPI: PE2/BK1_IO2, PB2/CLK, PD11/IO0, PD12/IO1, PD13/IO3, PB6/NCS<br>USART1: PB14/TX, PB15/RX<br>Crystal: PH0/HSE_IN, PH1/HSE_OUT, PC14/LSE_IN, PC15/LSE_OUT<br>SWD: PA13, PA14 |

### Source File Layout (under `Core/`)

| File                          | Role                                              |
| ----------------------------- | ------------------------------------------------- |
| `Src/main.c`                  | Entry point, MPU config, system/periph clock init |
| `Inc/main.h`                  | Main header, includes `stm32h7xx_hal.h`           |
| `Src/gpio.c`                  | GPIO clock enable (all ports)                     |
| `Src/dma.c`                   | DMA1 clock enable, DMA1_Stream0 IRQ config        |
| `Src/quadspi.c`               | QSPI init + MSP init/deinit (pin mux)             |
| `Src/usart.c`                 | USART1 init + MSP init/deinit (pins + DMA link)   |
| `Src/stm32h7xx_it.c`          | All ISRs (SysTick, DMA1_Stream0, fault handlers)  |
| `Src/stm32h7xx_hal_msp.c`     | Global HAL MSP (SYSCFG clock)                     |
| `Src/memorymap.c`             | Placeholder (empty, CubeMX-generated)             |
| `Src/syscalls.c`              | Newlib stubs (_write uses `__io_putchar`)         |
| `Src/sysmem.c`                | Heap/stack allocation for newlib                   |
| `Src/system_stm32h7xx.c`      | System init (FPU, vector table offset, etc.)      |

### Initialization Order (in `main()`)

```
MPU_Config() → SCB_EnableICache() → SCB_EnableDCache() → HAL_Init()
→ SystemClock_Config() → PeriphCommonClock_Config()
→ MX_GPIO_Init() → MX_DMA_Init() → MX_QUADSPI_Init() → MX_USART1_UART_Init()
→ [bootloader logic placeholder]
```

## Project Rules

- **Drivers/** directory is entirely CubeMX auto-generated. Never modify these files — changes will be lost on re-generation. All user code lives under `Core/`.
- CubeMX config file: `Bootloader.ioc` (can re-generate project from this).
- USART1 DMA RX ISR is wired in `DMA1_Stream0_IRQHandler` → `HAL_DMA_IRQHandler(&hdma_usart1_rx)`.
- Debug via SWD (PA13/PA14), SysTick configured as HAL timebase.
- `USE_PWR_LDO_SUPPLY`, `USE_HAL_DRIVER`, `STM32H750xx` are defined globally via Makefile `C_DEFS`.
