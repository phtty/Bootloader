# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

STM32H750VBTx Bootloader project, generated by STM32CubeMX v6.14.1. Target chip has only 128KB internal flash — external QSPI flash (W25Q64, 8MB) provides additional storage. The bootloader receives firmware via USART1 (115200-8N1) and programs it into QSPI flash, then jumps to the application.

## Build Commands

```bash
make          # Build: generates build/Bootloader.elf, .hex, .bin
make clean    # Delete build/ directory
```

Toolchain: `arm-none-eabi-gcc` (must be on PATH or set `GCC_PATH`).
Optimization: `-Og`, debug symbols enabled (`-g -gdwarf-2`).

## Architecture

### Memory Layout (linker script: `STM32H750XX_FLASH.ld`)

| Region   | Address      | Size  | Notes                          |
| -------- | ------------ | ----- | ------------------------------ |
| ITCMRAM  | `0x00000000` | 64K   |                                |
| FLASH    | `0x08000000` | 128K  | Internal, read-only            |
| DTCMRAM  | `0x20000000` | 128K  | .data, .bss, heap, stack       |
| RAM (D1) | `0x24000000` | 512K  |                                |
| RAM_D2   | `0x30000000` | 288K  |                                |
| RAM_D3   | `0x38000000` | 64K   |                                |
| QSPI     | `0x90000000` | —     | External flash, memory-mapped  |

### Clock Tree

- **HSE** → PLL1 (÷5, ×192, ÷2) → **480 MHz** SYSCLK, **240 MHz** HCLK, **120 MHz** APB
- **HSE** → PLL2 (÷16, ×192, ÷2) → VCO=300MHz, R=**150 MHz** (QSPI), Q=**75 MHz** (USART1)
- QSPI prescaler=1 → **75 MHz** actual QSPI clock
- LSI enabled (32.768kHz) for RTC
- PWR: LDO supply, voltage scaling 0 (highest performance)

### MPU Configuration (`Platform/Src/pl_mpu.c` — `MPU_Config`)

Deny-by-default strategy with selective whitelisting:
1. **Region 0**: Deny entire 4GB (background), except sub-regions 0,1,2,7 (`SubRegionDisable=0x87`)
2. **Region 1**: `0x90000000`, 8MB — full access, executable, cacheable (QSPI flash)
3. **Region 2**: `0x20000000`, 1MB — full access, NOT cacheable (DTCM)

I-Cache and D-Cache are enabled after MPU config, before HAL init.

### Peripherals

| Peripheral | Details                                                  |
| ---------- | -------------------------------------------------------- |
| QUADSPI    | Single bank, FlashSize=23 (8MB), prescaler=1 (75 MHz), half-cycle sample shift |
| USART1     | 115200-8N1, DMA RX (DMA1_Stream0, peripheral→memory, byte-aligned, normal mode) |
| CRC        | Hardware CRC unit: CRC-16-CCITT for protocol frames, CRC32-MPEG2 for firmware images |
| RTC        | LSI clock source, 24H format, asynch_prediv=127, synch_prediv=255 |
| GPIO       | QSPI: PE2/BK1_IO2, PB2/CLK, PD11/IO0, PD12/IO1, PD13/IO3, PB6/NCS<br>USART1: PB14/TX, PB15/RX<br>Crystal: PH0/HSE_IN, PH1/HSE_OUT, PC14/LSE_IN, PC15/LSE_OUT<br>SWD: PA13, PA14 |

### Layered Architecture

```
Application/     # 业务逻辑：Bootloader 协议、固件管理
  ├── app_bootloader.c/h   # 主循环：收帧 → 处理 → ACK
  ├── app_protocol.c/h     # 协议帧收发 + 命令分发 (CRC16 硬件校验)
  └── app_firmware.c/h     # 固件写入/校验/跳转 (CRC32 硬件校验)

Device/          # 设备驱动：QSPI Flash 器件、Console 控制台
  ├── dev_qspi_flash.c/h   # Flash 读写/擦除/内存映射/Quad 模式
  └── dev_console.c/h      # 串口 DMA 空闲中断收发

Platform/        # 平台抽象：HAL 封装 + MSP 回调
  ├── pl_mpu.c/h           # MPU 区域配置
  ├── pl_clock.c/h         # 系统时钟 + 外设共用时钟
  ├── pl_gpio.c/h          # GPIO 端口时钟使能
  ├── pl_dma.c/h           # DMA1 时钟 + IRQ 配置
  ├── pl_qspi.c/h          # QSPI 外设初始化
  ├── pl_uart.c/h          # USART1 + DMA RX 初始化
  ├── pl_crc.c/h           # 硬件 CRC 单元 (CRC16/CRC32)
  └── pl_rtc.c/h           # RTC 时钟 + 日历初始化

Kernel/          # 内核基础设施
  └── initcall.c/h         # 类似 Linux 的 initcall 自动初始化框架

Core/            # STM32CubeMX 生成（仅保留必要文件）
  ├── main.c               # 入口：board_init() → app_bootloader_run()
  ├── stm32h7xx_it.c       # ISR 向量（SysTick + fault handlers）
  ├── stm32h7xx_hal_msp.c  # 全局 HAL MSP (SYSCFG 时钟)
  ├── syscalls.c           # Newlib 桩
  ├── sysmem.c             # _sbrk 堆分配器
  └── system_stm32h7xx.c   # 系统初始化 (FPU, 向量表偏移)
```

### Initialization Order (`board_init()` in `Kernel/Src/initcall.c`)

Phase 1 — 手动顺序（关键路径）:
```
MPU_Config() → SCB_EnableICache() → SCB_EnableDCache() → HAL_Init()
→ SystemClock_Config() → PeriphCommonClock_Config()
```

Phase 2 — initcall 自动发现（按链接段优先级）:
```
arch_initcall(1):   pl_gpio_init()
subsys_initcall(2): pl_dma_init()
device_initcall(3): pl_qspi_init(), pl_uart_init(), pl_crc_init(), pl_rtc_init()
driver_initcall(4): dev_qspi_flash_init(), dev_console_init()
```

## Project Rules

- **Drivers/** directory is entirely CubeMX auto-generated. Never modify these files — changes will be lost on re-generation.
- **Core/** files are CubeMX-generated entry points. After CubeMX re-generation, main.c must be restored with `board_init()` + `app_bootloader_run()` (preserved in USER CODE blocks). Other Core files are kept as-is (HAL config, ISRs, syscalls).
- User application code lives under `Application/`, `Device/`, `Platform/`, and `Kernel/`.
- CubeMX config file: `Bootloader.ioc` (can re-generate project from this).
- USART1 DMA RX ISR is in `Platform/Src/pl_uart.c` — `DMA1_Stream0_IRQHandler` → `HAL_DMA_IRQHandler(&hdma_usart1_rx)` → callback to Device layer.
- Debug via SWD (PA13/PA14), SysTick configured as HAL timebase.
- `USE_PWR_LDO_SUPPLY`, `USE_HAL_DRIVER`, `STM32H750xx` are defined globally via Makefile `C_DEFS`.
